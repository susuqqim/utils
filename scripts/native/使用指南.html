WorkBuddy2API 使用指南

照着做就行 · 不用懂编程 · 大约 5 分钟
（真的，宝宝也能看懂）

这是什么？

把你的 WorkBuddy / CodeBuddy 账号变成一个本地的小型 AI 接口。 这样 Cursor、Cline、Cherry Studio 这些 AI 软件，就能用上你账号里的额度了。

🔒 只在你自己的电脑上运行，不对外开放，别人访问不到。

开始前，先确认 2 件事

  1. 电脑是 Windows 10 / 11（本页以 Windows 为例，Mac 和 Linux 见文末）。
  2. 你有一个 WorkBuddy 或 CodeBuddy 账号（第 4 步要用它登录）。
⚠️ 先解压！不要直接在压缩包里双击运行，会出错。
解压后文件夹里应该能看到 install.ps1、wb2api-windows-amd64.exe、使用指南.html（就是本页）这些文件。

第 1 步安装（约 1 分钟）

  1. 打开解压出来的文件夹。
  2. 在文件夹的空白处按住 Shift 再点鼠标右键，选择 「在此处打开 PowerShell 窗口」（Windows 11 叫「在终端中打开」）。
  3. 在弹出的窗口里，复制下面这一行，粘贴进去，按回车：
powershell -ExecutionPolicy Bypass -File .\install.ps1

看到 ==> done 就是装好了，这个窗口可以关掉。

更简单：用 Windows 安装包（.msi）双击安装

如果同目录里还有 workbuddy2api-1.11.6-x64.msi，直接双击它就能装， 全程不需要管理员，还会自动帮你建好桌面和开始菜单快捷方式。 装完从第 2 步继续即可。

两种装法二选一（装在同一个位置，别混用）。卸载在「设置 → 应用 → 已安装的应用」里找 WorkBuddy2API，默认会保留你的账号数据。

右键没有那个菜单？点这里

按 Win + R，输入 powershell 回车，然后依次粘贴这两行（每行按一次回车）：

cd "这里粘贴你解压出来的文件夹路径"
powershell -ExecutionPolicy Bypass -File .\install.ps1

小技巧：在文件夹地址栏点一下、按 Ctrl+C 就能复制路径。

第 2 步设一个属于你自己的"密码"（约 30 秒）

这个密码（API Key）是你自己随便想一个，不是从网上申请的，也不是账号密码。 它的作用只有一个：让你电脑上的 AI 软件连上这个网关。

关掉刚才的窗口，重新开一个新的 PowerShell 窗口，粘贴下面这行（把中文换成你自己的）：

wb2api setkey 我的密码123

建议用字母 + 数字，例如 mykey2026。请记下来，第 5 步还要用。

提示「wb2api 不是内部或外部命令」？点这里

说明新命令还没生效（需要新开窗口）。用完整路径代替即可：

& "$env:LOCALAPPDATA\workbuddy2api\wb2api.cmd" setkey 我的密码123

第 3 步启动（约 10 秒）

在同一个窗口里，粘贴并回车：

wb2api start

看到 Started. Panel: http://127.0.0.1:17963/panel/ 就成功了。

💡 这一步之后，网关就在后台运行了。可以关掉窗口，不影响使用。
🖥️ 右下角任务栏通知区会出现一个小图标（托盘）。 左键单击 = 打开管理面板；右键菜单里有「重启服务 / 开机自启 / 退出」。 看不到的话，点一下任务栏上的 ^ 展开隐藏图标。

第 4 步登录你的账号（约 1 分钟）

  1. 打开浏览器，访问：http://127.0.0.1:17963/panel/
  2. 把第 2 步设的密码粘进去，进入管理面板。
  3. 点面板里的「添加账号」，按提示用 WorkBuddy / CodeBuddy 扫码或打开授权链接登录。
💡 建议加 2 个以上账号：某个号被限流时，网关会自动换号，不容易中断。

第 5 步在 AI 软件里填 3 个格子

打开你的 AI 软件（Cursor / Cline / Cherry Studio / Roo 等），找到"添加模型 / OpenAI 兼容 / 自定义 API"的地方，填：

要填的格子填什么
接口地址 / Base URLhttp://127.0.0.1:17963/v1
API Key / 密钥第 2 步你自己设的那个（例如 mykey2026）
模型 / Modelglm-5.3 或 deepseek-v4.1-flash 或 kimi-k2.7

完整可用模型列表在面板里能看到。填完点"测试连接"，能通就成了。

以后日常使用：记住 3 条命令

想做什么输入
启动wb2api start
停止wb2api stop
看看还活着吗wb2api status

电脑重启后需要再 wb2api start 一次；不想每次手动，看下面「想开机自动启动」。

让 AI Agent 帮你接入其他软件（可选，很省事）

如果你在用 DSH、Claude Code，或者 Cursor 里那种能读写本机文件的 Agent，可以直接让它替你把网关配置到别的软件里。 把下面整段复制发给它，并把尖括号里的内容换成你的实际情况。

【复制给 AI Agent 的指令】 你的任务：把本机已经在运行的 WorkBuddy2API 网关，接入到 <目标软件>。 网关信息（必须原样使用，不要改写）： - Base URL : http://127.0.0.1:17963/v1 - API Key : <把你第 2 步设的那个填在这里> - 协议 : OpenAI Chat Completions（支持 SSE 流式） - 模型名 : 先用 GET /v1/models 拉完整列表；常用的有 glm-5.3、deepseek-v4.1-flash、kimi-k2.7 - 可选前缀 : cn:<模型名> 强制国内版；global:<模型名> 强制国际版（前缀在出站前会被网关剥离） 硬性要求： 1. 只修改 <目标软件> 里 workbuddy2api 这一个 provider，其它 provider 原样保留； 2. 改配置文件前先备份一份（文件名加时间戳后缀）； 3. 改完用一次最小请求验证连通（POST /v1/chat/completions，max_tokens 设为 8），把 HTTP 状态和返回内容告诉我； 4. 不要把 API Key、账号凭证写进日志，也不要上传到任何地方； 5. 不要修改网关的监听地址（必须保持 127.0.0.1），不要把它暴露到局域网或公网； 6. 如果 <目标软件> 不支持自定义 Base URL，直接告诉我，不要擅自换成别的方案。 目标软件：<Cursor / Cline / Cherry Studio / OpenCode / DSH / Claude Code / Roo …> 配置文件位置：你自己找（找不到就问我）。

常见软件大致要改哪里

软件位置（让 Agent 自己确认）
DSH~/.dsh/settings.yaml + .credentials.yaml（Windows：%USERPROFILE%\.dsh\）
OpenCode~/.config/opencode/opencode.json
Cherry Studio设置 → 模型服务 → 添加「OpenAI 兼容」自定义提供商
CursorSettings → Models → OpenAI API Key → Override Base URL
Cline / Roo CodeAPI Provider 选「OpenAI Compatible」→ 填 Base URL + Key

想自己动手确认一下？

curl --noproxy "*" http://127.0.0.1:17963/v1/models -H "Authorization: Bearer 你的密码"

能返回一长串模型名，就说明网关和密钥都没问题。

💡 给 Agent 的更完整接入说明（端点契约、模型前缀、错误码语义：403/11140 别重试、429/6004 网关自动冷却、499 是客户端取消）见项目仓库里的 AGENTS.md。

常见问题

杀毒软件（火绒 / 360）提示"修改启动项 / 疑似木马"？
这是杀毒软件对"开机自启"的误报，不是病毒。自启由程序自己写一条启动记录完成。 处理：在杀毒软件里把文件夹 %LOCALAPPDATA%\workbuddy2api 加入信任区（或弹窗里选"信任"）。 你也可以干脆不开自启——手动 wb2api start 一样用。
Windows 提示"未知发布者"或被 SmartScreen 拦下？
因为程序没有购买数字签名证书。点「更多信息」→「仍要运行」即可。
想开机自动启动？
执行 wb2api autostart on；查看状态 wb2api autostart status；关闭 wb2api autostart off。 如果被安全策略拦住，再用 wb2api autostart on --startup-folder。
提示端口 17963 被占用？
通常是已经启动过一次（重复启动）。先 wb2api stop，再 wb2api start。 也可以换个端口：设置环境变量 WB2API_PORT=18063 后再启动。
AI 软件里测试连接报 502 / 连不上？
多半是电脑上开了代理软件（Clash / v2rayN 等）。请把 127.0.0.1 和 localhost 加入代理的"绕过 / 直连"列表。
我的账号和数据放在哪里？
程序在 %LOCALAPPDATA%\workbuddy2api\；账号凭证与配置在 %USERPROFILE%\.workbuddy2api\。 备份或搬家时，复制后一个文件夹即可。
怎么升级？
先 wb2api stop，然后用新版本目录重新跑一次 install.ps1，再 wb2api start。 配置和账号都会保留。
怎么彻底卸载？
wb2api autostart off → wb2api stop → 删除 %LOCALAPPDATA%\workbuddy2api 和 %USERPROFILE%\.workbuddy2api 两个文件夹。

Mac / Linux 用户

命令几乎一样，只是装的时候在解压目录里执行：

./install.sh

之后的 setkey / start / status / autostart 完全相同。 如果提示没有权限，先执行 chmod +x install.sh。

macOS 首次运行可能提示"无法验证开发者"，在「系统设置 → 隐私与安全性」里点"仍要打开"即可。

最后一句安全提醒

你设的那个 API Key、以及 %USERPROFILE%\.workbuddy2api 里的账号凭证， 都相当于你账号的钥匙，不要发给别人、不要上传网盘。

本程序只监听本机 127.0.0.1；请勿改成 0.0.0.0 暴露到局域网或公网。

使用本程序请遵守 WorkBuddy / CodeBuddy（及上游）的服务条款；本项目与上游无关联。
